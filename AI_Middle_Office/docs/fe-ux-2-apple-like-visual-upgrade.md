# FE-UX-2 Apple-like 正式视觉增强第一版

> 日期：2026-06-02  
> 状态：FE-UX-2-1 第一版已完成并通过人工视觉验收  
> 范围：Vite 管理台 + 旧 `index.html` 报价工作台视觉底座

## 1. 背景

FE-UX-1 已完成“保守型体验重构”，主要解决流程清晰、信息不溢出、关键页面可用性和试运行验收清单。用户希望进一步让前端界面看起来更正式、工整、雅观，并提到“苹果官网那样”的界面气质。

本阶段不套 Apple 官网模板、不复刻 Apple 品牌视觉，也不把企业中后台改成官网式营销页；只提取适合内部系统的视觉原则：浅色、留白、精致边界、克制阴影、统一圆角、清晰层级和更正式的品牌入口。

## 2. 本轮目标

- 让系统从“能用且清楚”向“更正式、更干净、更像可试运行产品”推进一档。
- 不改变报价、成本库、项目进度、经营驾驶舱等任何业务规则。
- 不引入新 UI 库、不更换 Vue3 + Vite + Element Plus 技术栈。
- 不整站套模板、不迁移旧 `index.html` 到 Vite。
- 优先统一视觉底座，为后续逐页精修留出稳定方向。

## 3. 已落地内容

### 3.1 Vite 管理台

涉及文件：

- `ai-web/src/App.vue`
- `ai-web/src/style.css`

已完成：

- 顶部栏调整为浅色磨砂、品牌 lockup 和 `QS` 品牌标识。
- 登录页由单一登录卡片改为左右结构：品牌介绍区 + 登录面板。
- 全局视觉 token 调整为浅灰背景、白色面板、浅边框、蓝色主操作、克制阴影。
- Element Plus 通用控件增强：
  - 按钮统一圆角、字重和主按钮阴影。
  - 输入框、选择器、文本域统一浅边框和 focus halo。
  - 表格表头、悬停行、弹窗、抽屉、标签统一视觉密度。
- 管理台核心卡片统一：
  - 指标卡、经营总览区块、成本库工作台、项目概览卡片统一 `12px` 圆角、白底、轻阴影。
  - toolbar / filter / empty panel 从硬灰底改为更轻的白色半透明面板。
- 移动端登录布局补充响应式规则。

### 3.2 旧报价工作台

涉及文件：

- `index.html`

已完成：

- 顶部导航从深色条改为浅色磨砂导航，品牌标识与 Vite 管理台保持一致。
- 页面背景、主卡片、消息区、输入区调整为浅色正式工作台风格。

  - Element Plus 表格、按钮、输入框、弹窗统一基础视觉。

## 4. 明确不做

- 不修改任何后端接口。
- 不新增数据库结构或 Alembic。
- 不改变报价价格口径、成本库 active 规则、RAG 同步、草稿保存、推送阻断、项目硬门禁或审计规则。
- 不引入 ECharts、Tailwind、Ant Design、PrimeVue 或模板工程。
- 不做大屏化、官网化、营销页化。
- 不使用 Apple 商标、Apple 文案或 Apple 官网素材。

## 6. 人工验收记录

已按以下页面范围完成人工视觉验收：

1. `/login`：确认品牌入口是否更正式，登录面板是否干净，不显得过度营销。
2. `/admin/dashboard`：确认经营总览、指标卡、风险列表、趋势/分布概览是否更工整。
3. `/admin/cost-db`：确认成本库筛选、摘要卡、批量操作条、表格是否更像正式后台。
4. `/admin/projects`：确认项目进度列表和概览卡片是否清楚、不过度花哨。
5. `/index.html`：确认旧报价工作台顶部、流程条、聊天区、底部输入区是否协调。
6. AI 预审弹窗：确认总额摘要、风险阻断、逐行报价表和底部操作区是否更清晰。

验收关注项：

- 页面是否过白、过冷或太像“空白模板”。
- 主操作按钮是否容易识别。
- 表格密集页面是否仍然好扫读。
- 旧报价页和 Vite 管理台之间是否有明显割裂。
- 窄屏下登录页、成本库、预审弹窗是否仍能正常阅读。

## 7. 后续可选方向

若继续深化视觉质量，后续可继续 FE-UX-2-2：

- 对报价工作台和预审弹窗做更细的视觉分层，而不仅是全局 CSS 增强。
- 为经营总览补轻量图形化视觉，但继续避免炫酷大屏。
- 为成本库表格补更正式的列密度、行详情抽屉和批量操作视觉。
- 统一空状态、错误状态、加载状态和确认弹窗。

若本轮方向过于冷淡或过于“苹果感”，可调整为更稳的企业中后台风格：保留浅色和工整，降低阴影、扩大表格密度、减少登录页品牌表达。
