# FE-UX-1 试运行体验验收包

> 状态：2026-06-02 已形成验收包，FE-UX-1 保守型体验重构一期已通过人工验收。本包后续用于小范围试运行问题登记；只记录前端体验问题，不改变业务规则、权限、价格口径、成本库 active 规则、项目硬门禁或审计口径。

## 一、验收范围

| 页面 | 角色 | 优先级 | 检查重点 |
|---|---|---|---|
| 旧报价工作台 `index.html` | 业务员 | P0 | 流程步骤、底部操作、任务恢复、预审弹窗 |

## 二、角色验收清单

### 业务员

- 能在报价工作台 30 秒内看懂当前步骤和下一步动作。
- 能从历史或恢复提示继续未完成报价任务。
- 能在预审弹窗先看到总价、风险、成本依据覆盖，再进入逐行改价。
- 能明确区分保存草稿、关闭、打回重填、确认下发。
- 普通业务员不能进入完整成本库敏感明细。

### 成本部

- 能快速筛选 draft、AI 建议来源、无底价沉淀条目和 active 条目。
- 能在成本库顶部看到当前筛选结果、当前页状态、已选条目和 RAG 同步状态。
- 批量核定、恢复 draft、归档前能看清选中数量和可操作数量。
- 能进入详情、状态与流向、同步记录和审计记录。

### 项目经理

- 能在项目列表看到风险项目、任务闭环和进行中项目。
- 能在项目详情先看到项目编号、客户、经理、阻塞/逾期和证据完整性。
- 能定位缺证据任务、无证据已完成任务和硬门禁任务。
- 放行关键节点前能看到证据阻断和放行原因要求。

### 管理员 / 管理层

- 能在经营总览看到报价、成本库、项目证据和系统运行四类试运行读数。
- 能从风险列表或快捷入口跳转到对应页面。
- 能区分局部降级、业务风险和数据为空。
- 能用成本库、报价、项目进度页面做试运行日常巡检。

## 三、核心链路验收

| 链路 | 期望结果 |
|---|---|
| 报价输入到预审 | 流程步骤清楚，任务运行和恢复状态明确 |
| 预审人工确认 | 阻断原因集中，风险行可定位，价格字段含义清楚 |
| 预审草稿恢复 | 关闭后可从历史继续，保存状态可见 |
| 成本库筛选审核 | draft / active / archived 状态清晰，批量操作条不遮挡表格 |
| 成本库证据追溯 | 详情、状态流向、审计、同步记录入口清楚 |
| 经营总览巡检 | 管理层能先看四类试运行读数，再看指标卡和风险列表 |
| 项目进度巡检 | 项目经理能先看风险、阻塞、证据缺口，再进任务表 |

## 四、窄屏检查

- 页面宽度约 390px、768px、1366px 各检查一次。
- 顶部操作区按钮允许换行，但不能遮挡标题或内容。
- 指标卡和概览卡允许变成单列或双列，但文字不能溢出卡片。
- 表格允许横向滚动，但筛选区、批量操作条和分页不能互相覆盖。
- 弹窗底部按钮允许换行，但确认下发、保存草稿、关闭、打回重填必须可见。

## 五、问题登记模板

| 字段 | 填写说明 |
|---|---|
| 编号 | FE-UX-ISSUE-001 起 |
| 日期 | 发现日期 |
| 页面 | 页面路径或弹窗名称 |
| 角色 | 业务员 / 成本部 / 项目经理 / 管理员 |
| 操作步骤 | 从登录到复现的关键步骤 |
| 期望结果 | 用户认为应该看到或能做什么 |
| 实际结果 | 实际看到的问题 |
| 问题类型 | UI / 操作动线 / 业务口径 / 权限 / 数据质量 / 性能 |
| 优先级 | P0 阻断试运行 / P1 影响效率 / P2 可后续优化 |
| 截图或报错 | 附截图、接口错误或控制台错误 |
| 处理状态 | 待确认 / 已确认 / 修复中 / 已修复 / 暂缓 |

## 六、每日试运行检查项

- 报价工作台是否能登录、发起报价、进入预审。
- 成本库是否能打开，筛选和详情是否正常。
- 经营总览是否能打开，是否存在局部降级告警。
- 项目进度是否能打开，项目列表和我的任务是否正常。
- 是否出现按钮遮挡、文字溢出、表格无法滚动、弹窗无法关闭。
- 是否出现普通角色看到敏感成本明细或管理员看不到必要入口。

## 七、通过标准

FE-UX-1 一期通过条件：

- P0 问题为 0。
- P1 问题已修复，或有明确临时处理办法。
- P2 问题已登记，可进入后续视觉增强或二期体验优化。
- 报价、成本库、经营总览、项目进度四条核心入口在桌面宽度下无明显遮挡、错位和操作断点。

暂缓进入小范围试运行的条件：

- 业务员无法完成报价预审和下发。
- 成本部无法筛选或审核 draft。
- 项目经理无法定位阻塞或缺证据任务。
- 管理员无法打开经营总览或关键巡检页面。
