# BIZ-3b-2a 无证据提交/完成软提醒

## 背景

BIZ-3b-1 已支持为项目任务登记成果证据。本阶段把成果证据和任务推进动作轻量连接起来：当一个有成果要求的任务没有证据时，提交和完成动作会提醒用户，但不进入硬门禁。

本阶段不改变 2580 进度规则，不强制所有节点上传文件，不接钉钉/企微。

## 规则

### 提交到 80%

适用条件：

- 任务有成果要求，例如 EPC 模板的 `epc_deliverable`。
- 当前任务 `evidence_count=0`。

前端行为：

- 点击 `提交` 时弹出提醒：
  `当前节点尚未登记成果证据，建议补充后再提交。是否仍继续提交？`
- 用户可选择继续提交或先补证据。

后端行为：

- 允许提交。
- 写入事件 `task_submitted_without_evidence`。
- 事件消息：`无成果证据提交确认：用户确认继续提交`。

### 完成到 100%

适用条件：

- 任务有成果要求。
- 当前任务 `evidence_count=0`。

前端行为：

- 项目经理点击 `完成` 时弹出说明框。
- 必须填写仍确认完成的原因。

后端行为：

- 若没有填写 `confirm_without_evidence_reason`，返回 `422 EVIDENCE_CONFIRM_REASON_REQUIRED`。
- 填写原因后允许完成。
- 写入事件 `task_completed_without_evidence`。

示例消息：

`无成果证据仍确认完成：纸质资料已线下留存，稍后补传`

## API 变化

`POST /api/v1/admin/project-tasks/{task_id}/submit`

可选请求体：

```json
{
  "confirm_without_evidence_reason": "用户确认无证据提交"
}
```

`POST /api/v1/admin/project-tasks/{task_id}/complete`

当有成果要求且无证据时，必须带：

```json
{
  "confirm_without_evidence_reason": "纸质资料已线下留存，稍后补传"
}
```

无成果要求的普通任务保持原有行为，不要求填写说明。

## 前端变化

- `提交`：无证据时弹确认框，允许继续。
- `完成`：无证据时弹输入框，要求填写说明。
- 项目动态新增事件显示：
  - `无证据提交`
  - `无证据完成`

## 当前边界

- 这仍是软提醒，不是硬门禁。
- 只对有成果要求的任务生效，避免影响普通手工任务。
- 有证据时提交/完成不增加额外步骤。
- 文字证据、链接证据、文件证据均计入证据数量。

## 验收口径

1. EPC 任务无证据时点击 `提交`，应出现提醒。
2. 选择继续提交后，任务进入 `待确认 / 80%`。
3. EPC 任务无证据时点击 `完成`，应要求填写确认说明。
4. 填写说明后任务可进入 `已完成 / 100%`。
5. 项目动态中能看到 `无证据提交` 和 `无证据完成`。
6. 已有证据的任务提交/完成不弹出无证据提醒。
7. 无成果要求的普通任务不受影响。

## 后续

BIZ-3b-2b 可以继续做项目详情缺证据汇总，例如在项目顶部显示：

`缺成果证据节点 12 个`

BIZ-3b-3 再考虑关键节点硬门禁。
