# 试运行版用户速查手册

更新时间：2026-06-03

## 1. 适用对象

本手册面向小范围内网试运行参与人员：

- 报价业务员。
- 成本库参与人员。
- 项目进度维护人员。
- 管理层只读观察者。

本手册只说明常用操作路径，不解释系统架构。

## 2. 登录入口

本机：

```text
http://127.0.0.1:9000/login
```

内网其他设备：

```text
http://<Windows 当前内网 IP>:9000/login
```

当前已验证内网地址：

```text
http://192.168.110.138:9000/login
```

如果打不开，先联系管理员确认当天 `LAN URL`。

## 3. 登录后看不到入口怎么办

可能原因：

- 账号角色没有分配。
- 功能开关未开启。
- 登录后角色版本未刷新。
- 当前账号不是试运行账号。

处理：

1. 退出登录后重新登录。
2. 仍看不到时，把账号名发给管理员。
3. 不要借用管理员账号继续操作。

## 4. 报价业务员路径

常用路径：

```text
/index.html
```

建议流程：

1. 登录系统。
2. 进入报价工作台。
3. 上传或输入客户需求。
4. 等待 AI 预审结果。
5. 在预审弹窗中检查：
   - 项目名称。
   - 工程量。
   - 单位。
   - 参考单价。
   - 成本库参考。
   - 无底价提示。
   - 疑似漏项提示。
6. 必要时人工修改。
7. 确认无误后下发。
8. 如不确定，先保存草稿或打回，不要强行下发。

注意：

- 无底价项目可以人工确认，但不代表成本库已正式启用。
- 系统建议价不是最终制度口径，试运行阶段仍以人工确认为准。
- 大清单如出现占位未补价，系统会阻断下发。

## 5. 需求单标准化路径

常用路径：

```text
/admin/requirement-standardization
```

建议流程：

1. 上传甲方需求单 Excel。
2. 按 Sheet 检查列映射。
3. 逐行确认或批量确认可报价行。
4. 关注阻断行和未通过校验行。
5. 只把已确认且通过校验的行发起报价。
6. 发起报价后回到旧报价工作台查看进度和预审。

注意：

- 说明行、汇总行、空白行不应进入报价。
- 阻断行不要绕过，应补清信息后再报价。

## 6. 成本库参与人员路径

常用路径：

```text
/admin/cost-db
```

按角色不同，可见能力不同：

- `cost_viewer`：查看成本库。
- `cost_editor`：维护 draft。
- `cost_approver`：核定 active、归档。
- `cost_exporter`：导出。

注意：

- draft 不参与正式报价参考。
- active 才参与报价、RAG 同步和底价兜底。
- 启用 active 应填写原因。
- 导出成本库属于敏感操作。

## 7. 项目进度路径

常用路径：

```text
/admin/projects
```

试运行阶段只做轻量维护：

1. 查看项目。
2. 查看任务节点。
3. 更新任务状态。
4. 按要求登记成果证据。
5. 关键节点缺证据时，不要随意强制完成。

注意：

- 当前项目规则还没有被公司正式统一定义。
- 试运行阶段发现流程不适配时，登记问题，不现场硬改规则。

## 8. 管理层只读路径

常用路径：

```text
/admin/dashboard
```

建议只看：

- 报价趋势。
- 响应速度。
- 项目风险。
- 成本/项目分布概览。
- 系统健康摘要。

注意：

- 当前经营总览是轻量 MVP。
- 演示数据和少量试运行数据不能代表真实 ROI。
- 完整经营模型、合同、回款、利润分析后续再做。

## 9. 常见提示

| 提示 | 含义 | 处理 |
|---|---|---|
| 无权限 | 当前账号角色不足 | 联系管理员，不借用账号 |
| 服务不可用 | 后端或依赖异常 | 联系管理员看健康检查 |
| 需求单无法解析 | Excel 格式或表头不清 | 先修需求单或人工映射 |
| 报价任务失败 | AI/N8N/RAG/队列可能异常 | 记录任务时间和错误提示 |
| 未补价占位阻断 | AI 未返回完整行 | 人工补价后再下发 |
| 无底价参考 | 成本库 active 未命中 | 人工确认，后续可沉淀 draft |

## 10. 问题反馈

发现问题时记录：

- 操作人。
- 账号。
- 页面。
- 时间。
- 输入文件或任务编号。
- 看到的错误提示。
- 截图。
- 是否阻断继续操作。

登记模板：

```text
reports/trial_readiness/20260603_stage3/trial_issue_log.csv
```
