# BIZ-3b-2b 项目详情缺证据汇总

## 背景

BIZ-3b-1 已支持任务成果证据登记，BIZ-3b-2a 已在无证据提交/完成时做软提醒。本阶段继续把证据状态放到项目详情页顶部，让项目经理一眼看到哪些岗位节点已经留痕、哪些节点缺成果证据、哪些节点已经完成但仍缺证据。

本阶段不新增数据库结构，不改变 2580 进度规则，不把缺证据升级为硬阻断。

## 后端返回

`GET /api/v1/admin/projects/{project_id}` 在项目详情 `data` 中新增 `evidence_summary`：

```json
{
  "required_task_count": 12,
  "evidenced_task_count": 5,
  "missing_evidence_task_count": 7,
  "done_without_evidence_task_count": 2,
  "open_missing_evidence_task_count": 5,
  "evidence_completion_percent": 42
}
```

字段口径：

- `required_task_count`：有成果要求的非取消任务数。
- `evidenced_task_count`：有成果要求且已有有效证据的任务数。
- `missing_evidence_task_count`：有成果要求但暂无有效证据的任务数。
- `done_without_evidence_task_count`：已完成但仍缺成果证据的任务数。
- `open_missing_evidence_task_count`：未完成且缺成果证据的任务数。
- `evidence_completion_percent`：已有证据节点数 / 有成果要求节点数，四舍五入为整数百分比。

证据口径沿用 BIZ-3b-1：文字、链接、文件证据都算有效证据；已软删除证据不计入。

## 前端交互

项目详情页新增“成果证据完整性”汇总区：

- 有成果要求节点
- 已留证据节点
- 缺证据节点
- 无证据已完成
- 未完成且缺证据

点击对应卡片后，下方“岗位任务”表格会切换到对应筛选结果；点击“清除筛选”回到全部任务。

筛选只影响当前项目详情页展示，不会修改任务状态、进度、阻塞状态或证据数据。

## 验收口径

1. 打开一个 EPC 项目详情，顶部应显示“成果证据完整性”汇总区。
2. 新建或选择一个有成果要求的任务，未上传证据时，“缺证据节点”数量应包含该任务。
3. 给该任务新增文字、链接或文件证据后，刷新详情，“已留证据节点”应增加，“缺证据节点”应减少。
4. 对无证据任务执行完成并填写确认原因后，“无证据已完成”应增加。
5. 点击“缺证据节点”“无证据已完成”“未完成且缺证据”等卡片，岗位任务表格应只显示对应任务。
6. 点击“清除筛选”后，岗位任务表格应恢复显示全部任务。

## 当前边界

- 仍然是透明化提醒，不做硬门禁。
- 取消任务不计入证据汇总。
- 普通无成果要求任务不计入缺证据统计。
- 外部钉钉/企微证据链接仍按普通链接证据保存，暂不做外部系统自动同步。

## 后续

BIZ-3b-3 可以继续做关键节点硬门禁，例如竣工验收、结算移交等节点在缺证据时不允许完成，或需要管理员确认后放行。
