# BIZ-3a-2 旗胜 EPC 流程模板

## 背景

本阶段基于用户提供的 `旗胜EPC项目管理部流程 .xlsx` 设计工程项目进度模板，目标是在 BIZ-3a 项目进度底座上快速生成旗胜 EPC 项目的标准阶段和岗位任务。

本阶段不新增数据库表，不改变 2580 进度规则，不接外部钉钉/企微审批。所有数据复用现有 `projects`、`project_stages`、`project_tasks`、`project_task_events`。

## 模板结构

Excel 流程共 5 个阶段、82 个工作节点：

| 阶段 | 权重 | 完整节点数 | 说明 |
| --- | ---: | ---: | --- |
| 市场开发阶段 | 10% | 10 | 客户获取、项目攻坚、设计签约 |
| 设计方案阶段 | 20% | 17 | 立项、方案、施工图、预算、成果交付 |
| 招投标阶段 | 25% | 21 | 投标、合约、劳务招采 |
| 生产交付阶段 | 35% | 27 | 开工、隐蔽、施工、验收、结算 |
| 售后服务阶段 | 10% | 7 | 满意度、服务响应、回访、质保金 |

模板支持两种创建模式：

| 模式 | 节点数 | 使用场景 |
| --- | ---: | --- |
| 精简节点 `compact` | 41 | 当前单人试运行，保留关键节点，降低维护成本 |
| 完整82节点 `full` | 82 | 后续多人协同或正式项目复盘 |

## 后端接口

新增接口：

`POST /api/v1/admin/projects/epc-template`

请求字段：

| 字段 | 说明 |
| --- | --- |
| `name` | 项目名称，缺省为 `旗胜EPC项目-YYYYMMDD` |
| `client_name` | 客户名称 |
| `address` | 项目地址 |
| `owner_department` | 负责部门，缺省为 `项目管理部` |
| `planned_start_at` | 计划开始时间 |
| `planned_finish_at` | 计划完成时间 |
| `mode` | `compact` 或 `full` |
| `description` | 项目备注 |

创建后返回：

| 字段 | 说明 |
| --- | --- |
| `stages` | 5 个 EPC 阶段，权重合计 100 |
| `tasks` | EPC 节点任务，默认负责人为当前账号 |
| `template.template_key` | `qisheng_epc_compact_v1` 或 `qisheng_epc_full_v1` |
| `template.task_count` | 本次创建的节点数 |

每个任务会额外返回：

| 字段 | 说明 |
| --- | --- |
| `owner_role` | Excel 的主导部门 |
| `epc_content` | Excel 的内容分类 |
| `epc_standard` | Excel 的执行标准 |
| `epc_assist_department` | Excel 的辅助部门 |
| `epc_supervise_department` | Excel 的监督部门 |
| `epc_deliverable` | Excel 的成果文件 |

## 前端入口

Vite 后台 `/admin/projects` 增加 `EPC流程模板` 按钮。

创建弹窗支持填写项目名称、客户、部门、地址、计划时间、备注，并选择：

- `精简节点`：默认选项，适合当前仅老板单人试运行。
- `完整82节点`：保留 Excel 全量流程，用于完整复盘或多人协同时启用。

`我的项目任务` 和 `项目详情` 的任务表会展示岗位/成果信息，使阻塞、回退、推进时能看到该节点对应的交付要求。

## 进度与阻塞规则

单个任务继续沿用 BIZ-3a 的 2580 规则：

- `todo`：0%
- `started`：25%
- `progressing`：50%
- `submitted`：80%
- `done`：100%

项目总进度仍按阶段权重和阶段内任务平均进度计算。阻塞、解除阻塞、回退均写入 `project_task_events`，便于追溯是谁、因为什么原因进行了处理。

## 当前边界

- 当前模板任务默认分配给创建人，符合“项目进度功能全完成前只有一个人使用”的试运行口径。
- 成果文件字段先作为文字要求展示，不做文件上传强制校验。
- 不自动同步钉钉/企微；后续若需要，可以在任务事件层增加消息推送或外部待办。
- 模板内容暂时写在服务层常量中，不做后台可编辑模板管理。

## 验收口径

- 能创建精简 EPC 项目，生成 5 个阶段和 41 个关键任务。
- 能创建完整 EPC 项目，生成 5 个阶段和 82 个完整任务。
- 任务详情能看到主导部门、执行标准、辅助部门、监督部门和成果文件。
- 项目任务能继续执行开始、推进、提交、完成、阻塞、解除阻塞和回退。
- 不新增 Alembic，不影响现有 BIZ-3a 项目和单人试运行模板。
