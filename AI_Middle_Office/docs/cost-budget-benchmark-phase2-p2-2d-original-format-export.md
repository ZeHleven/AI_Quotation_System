# 成本预算对标 Phase 2 P2-2D：原格式清单补价导出

日期：2026-07-23

## 目标

项目成本计价模块的业务口径调整为：

```text
原格式甲方清单 Excel
  （已有项目、项目特征、单位、工程量，但通常没有具体价格）
  -> 系统识别与标准化
  -> 企业定额/账户定额/AI 估算形成计价草稿
  -> 在原格式 Excel 基础上补充价格列
  -> 导出“原格式 + 价格”的清单
  -> 人工在 Excel 中最终修改
```

原清单本身已经有项目和工程量，缺的是价格。系统内部可以继续使用标准化清单、计价草稿、AI 估价和账户定额同步能力，但对人工交付的文件不再以“系统重排的新表”为主，而是在客户上传的原工作簿版式基础上补出价格结果。

## 业务原则

- 原表结构优先：保留 Sheet 顺序、行列位置、合并单元格、样式、列宽、页眉页脚和已有公式。
- 系统只补充价格结果：默认只新增或写入综合单价、合价、成本拆分和必要备注列。
- 不覆盖人工原始内容：项目名称、项目特征、单位、工程量等原始输入列不被系统改写。
- 原清单无价格列时，系统在原明细表右侧追加价格列，而不是重排整张表。
- 人工最终负责：导出文件定位为“系统估算后给人工修改的 Excel”，不是自动定稿。
- 可追溯：导出文件必须能追溯到导入批次、确认修订、计价草稿 revision、估价任务和导出时间。
- 安全失败：无法定位原始行时不强行写入，改为在导出说明 Sheet 标记“待人工填写”。

## 当前系统差距

现有预算项目导入已具备：

- `.xlsx/.xlsm` 上传解析；
- 表头映射和标准清单确认；
- 双模式计价草稿；
- 单行/批量 AI 估价；
- 人工改价和成本拆分编辑。

但目前仍有三个缺口：

- `budget_project_import_batches.source_file_object_id` 已预留，但当前导入多为 `metadata_only`，原始 Excel 二进制不一定可取回。
- 导入阶段会识别并锁定价格/金额类列用于防止参与工程量标准化；但真实业务里原清单经常没有价格列，所以导出阶段还需要支持“自动追加价格列”。
- 当前计价结果只在页面草稿表中展示，尚无“按原工作簿版式追加价格并导出”的接口和前端按钮。

## P2-2D-1：原件留存

导入甲方清单时同步把原 Excel 保存为文件对象：

- 使用已有 `file_objects` + MinIO 文件存储。
- `BudgetProjectImportBatch.source_file_object_id` 指向保存后的原件。
- `source_storage_mode=file_object` 表示可原格式导出。
- 若 MinIO 未启用，可继续 `metadata_only`，但原格式导出按钮应禁用并提示“原件未留存”。

不需要新增数据库表；优先复用现有字段。

## P2-2D-2：价格列生成与回填列识别

对每个明细 Sheet 的每一个系统报价字段，先按表头自动匹配，再决定回填还是追加。导出字段固定为：

1. 项目名称
2. 特征描述
3. 区域
4. 主材采购方式
5. 工程量
6. 不含税综合单价
7. 不含税综合合价
8. 人工费
9. 主材费
10. 辅材费
11. 税金
12. 主材费不含损耗
13. 损耗率
14. 机械费
15. 综合费
16. 管理费
17. 利润费
18. 措施费
19. 甲供材单价
20. 甲供材损耗金

处理规则：

- `项目名称`、`特征描述`、`区域`、`主材采购方式`、`工程量`用于原清单行定位。默认不改写用户原始内容，除非后续另行开放“同步标准化字段”选项。
- 其余字段以“原清单表头存在即写回原列”为优先原则；不存在时，才在原明细区域的最右侧追加缺失字段。
- 追加字段严格按上述固定顺序排列；即使只缺少其中几个字段，也按该顺序追加，不插入工程量列后方，不移动原有任何列。
- 表头匹配使用可维护的别名词典并进行标准化比较。例如：`不含税综合单价` 可匹配 `综合单价`、`除税综合单价`，`不含税综合合价` 可匹配 `综合合价`、`合价`、`金额`。发生多个候选列时，不自动猜测，改在导出说明 Sheet 标记并等待人工指定。
- 追加列沿用相邻明细列的宽度、边框、字体、对齐、数字格式和筛选区域风格；金额字段写为数值并使用金额格式，`损耗率` 写为数值百分比格式。
- 系统不会因为字段缺失而覆盖或删除原列；原表所有列的位置、合并单元格、公式与版式保持不变。

列处理来源按优先级：

1. 人工在表头映射区明确指定回填列。
2. 系统依据本阶段的 20 个系统字段及其别名自动匹配原表表头。
3. 对未匹配字段，在明细表最右侧自动追加对应标准列。
4. 若出现多个候选列或无法定位明细表右侧追加位置，只导出说明 Sheet，不写入存在歧义的字段。

## P2-2D-3：原格式回填导出

新增服务建议：

- `app/services/budget_pricing_original_export.py`
- 读取当前账号当前项目的 active 计价草稿。
- 通过 `source_file_object_id` 读取原 Excel。
- 使用 `openpyxl.load_workbook(..., data_only=False)` 保留公式和样式。
- 按 `source_sheet + source_raw_row_index` 定位原始行。
- 按“已有价格列或自动追加价格列”写入：
  - 系统报价字段中的项目、特征、区域、采购方式、工程量和全部价格拆分字段；
  - `effective_unit_price` 写入 `不含税综合单价`；
  - `line_total` 写入 `不含税综合合价`；
  - `pricing_breakdown` 依次写入人工费、主材费、辅材费、税金、主材费不含损耗、损耗率、机械费、综合费、管理费、利润费、措施费、甲供材单价、甲供材损耗金。
- 追加一个只读说明 Sheet，例如 `系统估算说明`。

导出文件名建议：

```text
{项目名称}_原格式计价草稿_{pricing_mode}_Rev{draft_revision}_{yyyyMMdd_HHmmss}.xlsx
```

## P2-2D-4：接口与页面

后端接口建议：

- `GET /api/v1/admin/budget-projects/{project_id}/pricing-draft/original-format-export`
- 查询参数：
  - `pricing_mode=enterprise_ai|account_strict`
  - `include_breakdown=true|false`
  - `include_system_note=true|false`

前端位置：

- `/admin/budget-projects/{project_id}` 的“项目成本计价 / 双模式计价草稿”区域。
- 在“一键生成报价”和“保存草稿”附近新增“导出原格式 Excel”。
- 当 `source_file.download_available=false` 时禁用按钮。
- 当存在未计价行时允许导出，但弹窗提示“仍有缺价行，导出后需人工补齐”。
- 按钮文案建议为“导出原格式报价 Excel”，避免用户误解为只下载原件。

## 导出说明 Sheet

导出文件应追加说明 Sheet，便于人工接手：

- 项目名称。
- 原导入文件名。
- 导入批次 ID、确认修订 ID。
- 计价模式。
- 草稿 revision。
- 行数、已计价行、缺价行、人工改价行、AI 估价行。
- 回填列识别结果。
- 自动追加价格列结果。
- 未回填原因列表。
- 系统生成时间。

该说明 Sheet 不作为业务清单，只用于审计和人工复核。

## 验收标准

- 上传一个带样式、合并单元格和多 Sheet 的 `.xlsx` 后，导出文件能保持原版式。
- 原清单没有任一系统报价字段时，导出文件只在原明细表最右侧追加该缺失字段，原有项目和工程量列位置不变。
- 原清单已有系统报价字段或别名列时，导出文件优先回填原列，不重复追加同义列。
- 追加字段顺序与本阶段 20 个系统字段顺序一致，不插入工程量列后方，不改变原表结构。
- 系统默认只写入价格、金额及成本拆分字段，不改写项目名称、特征描述、区域、主材采购方式和工程量；这些原始字段仍作为行定位依据。
- 同一条草稿行能准确回填到原 Sheet 原行号。
- 未匹配或 AI 失败行不伪造 0 元，导出备注标记“待人工补价”。
- 有人工改价时，导出采用人工价。
- 有 AI 估价但无人改价时，导出采用 AI 建议价，并在说明中标记来源。
- 原件未留存时导出接口返回明确错误，不生成重排版替代文件。
- `npm run build`、后端相关专项测试通过。

## 不做事项

- 不把导出的 Excel 视为系统正式定稿。
- 不自动覆盖客户原始工程量。
- 不自动写入企业定额 active。
- 不自动同步账户定额 active。
- 不为无法定位明细行或追加位置的 Sheet 强行写入。
- 不支持旧 `.xls` 原格式导出；旧格式仍要求另存为 `.xlsx`。

## 推荐实施顺序

1. P2-2D-1：导入时留存原 Excel 文件对象。
2. P2-2D-2：支持已有价格列回填和无价格列时右侧追加价格列。
3. P2-2D-3：实现后端原格式回填导出服务和接口。
4. P2-2D-4：前端增加“导出原格式 Excel”按钮、缺价提示和错误提示。
5. 用真实项目清单做视觉验收：重点看格式是否保留、价格是否落在正确列或新增列、缺价行是否清楚留给人工。
