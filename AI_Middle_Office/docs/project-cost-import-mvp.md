# 项目采购资料快速入库 MVP

## 目标

把项目采购单、订购单、询价/比价表中的实际价格沉淀为可追溯的企业成本数据候选，避免未经审核的数据直接污染当前 active 企业定额。

正式链路：

`采购文件 → 价格观察 → 去重候选 → 主库资源匹配 → 人工审核 → 新企业定额 draft → 既有版本启用流程 → RAG 同步`

## 数据边界

- 原始采购行写入 `enterprise_resource_price_observations`，保留项目、供应商、日期、源文件、Sheet 和原始行号。
- 聚合候选写入 `project_cost_price_candidates`，记录价格区间、中位建议价、波动率、置信度、风险等级和当前 active 资源匹配结果。
- 默认状态均为待审核；导入不会直接修改 active 企业定额、报价参考或 RAG。
- 运费、税金、车费、加工费等费用行保留为观察，但从材料价格候选中排除。
- 退货负数行保留为观察，但不参与建议价计算。
- 审核通过后生成一份完整的企业定额 draft。匹配资源会更新草稿资源价、关联组成单价/金额，并重算受影响定额主项；未匹配材料作为新资源进入草稿，但不会自动挂接到定额组成。

## 页面操作

在 `/admin/cost-db` 打开“项目采购入库”标签页：

1. 填写项目名称。
2. 选择 `.xlsx` / `.xlsm` / `.zip`，或选择项目文件夹。
3. 查看解析批次和候选数量。
4. 按风险、状态、关键词筛选，批量通过或驳回候选。
5. 审核通过后点击“生成企业定额草稿”。
6. 草稿继续沿用现有企业定额版本复核、启用和 RAG 同步流程。

网页单次上传保留 256MB 安全上限。超大项目目录使用本地流式预览/导入脚本，避免一次性把全部文件读入内存。

## 本地大目录预览

默认只读，不写数据库：

```powershell
cd AI_Middle_Office
C:\Users\12521\miniconda3\python.exe scripts\project_cost_import_mvp.py `
  --source-dir "D:\项目采购资料" `
  --project-name "项目名称"
```

确认当前用户 ID 和数据库环境后，可增加 `--commit --actor-user-id <ID>` 写入审核层。即使使用 `--commit`，也只创建价格观察和待审核候选，不修改 active 企业定额。

## 权限与开关

- 功能开关：`FEATURE_PROJECT_COST_IMPORT=true`，并依赖 `FEATURE_COST_DB=true`。
- 查看：管理员、成本查看/编辑/审批/导出角色。
- 上传与修正：管理员、成本编辑或审批角色。
- 批量通过/驳回、生成企业定额草稿：管理员或成本审批角色。

## 东莞香港中心项目验证

2026-07-13 使用真实项目目录执行只读预览：

- Excel 文件：289 份
- 成功识别：203 份
- 未匹配通用表头：86 份
- 读取失败：0 份
- 价格观察：4,712 条
- 有可用正价格的观察：4,287 条
- 精确去重候选：1,422 个
- 有重复观察且波动不超过 10%：532 个
- 有重复观察且波动达到 20%：136 个，必须重点人工复核

本轮结果是 MVP 通用规则的保守基线。86 份未识别文件保留在批次 manifest 中，后续针对瓷砖、石材、地漏和对账单等非标准模板增加专项解析器。
