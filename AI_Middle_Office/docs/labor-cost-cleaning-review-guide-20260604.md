# 旗胜劳务成本清洗复核指南

适用文件：`旗胜劳务成本清洗复核包_20260604.xlsx`

## 一、复核目标

本次复核不是重新录入整份成本表，而是确认系统清洗后的结果是否可以进入后续成本库人工审核流程。

业务部门主要复核 3 个 Sheet：

1. `价格异常待复核`
2. `项目特征包含关系保留项`
3. `疑似重复待复核`

`清洗主表` 是候选结果主表，建议抽检；`来源明细` 用于追溯原始工程项目和行号。

## 二、总体原则

- 只在同一个工种内判断是否合并。
- `综合单价` 和 `不含税综合单价` 分开维护，不混合平均。
- `分部分项工程 + 项目特征 + 单位 + 价格口径` 都一致，才适合作为同一成本条目。
- 项目特征存在包含关系时，默认保留两项，不自动合并。
- 规格、材料、厚度、施工范围、单位、计量口径不同，原则上不合并。
- 单价为 0、缺价或价格波动大的记录，不能直接进入最终成本主表，必须人工判断。

## 三、建议复核顺序

1. 先复核 `价格异常待复核`
2. 再复核 `项目特征包含关系保留项`
3. 最后复核 `疑似重复待复核`
4. 有疑问时到 `来源明细` 按 `清洗ID`、`来源Sheet`、`来源行号` 追溯原始记录

## 四、各 Sheet 怎么填

### 价格异常待复核

判断内容：

- 单价为 0 是否真实有效
- 是否缺少单价
- 同类记录价格波动超过 50% 或 100% 是否合理
- 是否需要修正单价、剔除或等待补充资料

主要填写：

- `人工复核结论`：选 `价格正确` / `修正单价` / `剔除` / `待补资料`
- `人工确认单价`：需要修正时填写最终单价
- `是否纳入主表`：选 `是` / `否`
- `处理方式`：选 `按原价保留` / `按确认单价修正` / `剔除该条` / `待补资料后再定`
- `复核说明`：写明判断依据
- `复核人`、`复核日期`

### 项目特征包含关系保留项

判断内容：

- 短项目特征和长项目特征是否属于不同施工内容
- 价格差异是否由施工范围、材料规格、工序差异造成
- 是否确实需要保留两项

主要填写：

- `人工复核结论`：选 `确认保留两项` / `仍需合并` / `待补资料`
- `处理方式`：选 `保留两项` / `合并到短项` / `合并到长项` / `重新命名后保留`
- `合并目标清洗ID`：需要合并时填写保留的目标 ID
- `人工修正项目特征`：需要规范表达时填写
- `复核说明`、`复核人`、`复核日期`

### 疑似重复待复核

判断内容：

- 条目 A 和条目 B 是否真的是同一种成本项
- 名称是否只是写法不同
- 项目特征、单位、规格、施工范围是否一致
- 是否需要合并、保留两项或重新命名

主要填写：

- `人工复核结论`：选 `合并` / `不合并` / `待补资料`
- `处理方式`：选 `合并到条目A` / `合并到条目B` / `保留两项` / `重新命名后保留`
- `合并目标清洗ID`：需要合并时填写
- `人工修正名称`、`人工修正项目特征`：需要规范名称或特征时填写
- `复核说明`、`复核人`、`复核日期`

## 五、典型判断口径

| 情况 | 建议判断 |
|---|---|
| 同工种、同名称、同项目特征、同单位、同价格口径 | 可合并 |
| 同名称但项目特征一个更详细、一个更简略 | 通常保留两项 |
| 同名称但材料厚度、规格、品牌、施工范围不同 | 不合并 |
| 同名称但单位不同，比如 `m` 和 `m2` | 不合并 |
| 价格波动超过 50% | 需要说明原因或修正 |
| 单价为 0 或缺少单价 | 修正、剔除或待补资料 |
| 只有单条样本 | 可保留为候选，但建议人工确认 |

## 六、复核完成标准

复核完成时，应满足：

- 3 个复核 Sheet 中需要判断的行均已填写 `人工复核结论`
- 涉及价格修正的行已填写 `人工确认单价`
- 涉及合并的行已填写 `合并目标清洗ID`
- `复核说明` 能解释主要判断依据
- `复核人`、`复核日期` 已填写

复核完成后，由数据维护人员根据人工结论更新 `清洗主表`，再进入成本库 `draft` 待审核流程。不要把未复核的异常项直接导入 `active` 成本库。
