# BIZ-2x DWG 准确工程量专项路线

日期：2026-06-15

## 目标

把 DWG 识图从“能列出可信项目”推进到“能按 GB/T 标准规则计算可信工程量”。最终链路必须是：

```text
图纸项目
  -> 对应房间/区域/构件
  -> CAD 几何证据
  -> GB/T 工程量计算规则
  -> 四字段 Excel：项目名称、项目特征、单位、工程量
```

## 当前状态

已完成：

1. GB/T 50854-2024 active 标准库已可用于项目名称、项目特征字段、单位、工程量规则查询。
2. DWG 可通过 ODA 转为 DXF，并提取文字、表格、材料/做法、普通标注和 CAD 几何候选。
3. 上传 DWG 后可生成“图纸项目识别结果”和“标准列项草稿四字段 Excel”。
4. 已增加项目质量闸门，过滤砂浆打底、龙骨间距、刮腻子工序、设计说明长句等非项目线索。
5. 已增加项目-CAD 绑定建议，避免把 0.0001㎡ 等局部碎片当工程量。
6. 已增加项目-区域绑定报告，优先用房间名、区域文字、项目标签和区域类型把项目绑定到 CAD 区域证据。
7. 已增加房间边界与净周长报告，把有房间标签的闭合区域整理为房间边界候选，并识别门洞/开口扣减候选。
8. 已增加首批专项算量 trace，把项目-区域绑定、房间净周长和标准规则证据转换为可复核建议量。
9. 已增加首批标准规则执行器，把标准库工程量规则映射为可执行模板并接入专项算量 trace。
10. 已增加专项 trace 复核导出与最终四字段生成链路，复用 BIZ-2x-6 四字段校验门禁。
11. 已增加 DWG 回归评估器，可对最近 3-5 套 DWG 列项结果生成识别覆盖、专项 trace 准备度、阻断原因和参考清单对比报告。
12. 已修正项目-区域绑定对门表/图框/立面/大样区域的误采纳风险，并支持最高分区域明显领先时进入“建议绑定区域，需复核”。
13. 已收敛 DWG 试运行前端展示口径：业务主界面只展示“项目名称、项目特征、单位、工程量”四字段清单，图纸线索、标准匹配线索、CAD trace 和绑定明细只保留为后台诊断/下载文件。

当前缺口：

1. 还不能保证每个房间/空间都能稳定识别到唯一封闭边界，未标注房间名的区域仍需增强。
2. 门洞/开口宽度仍可能缺失，净周长扣减需要继续结合门图块规格、门表或尺寸标注。
3. 墙面涂料展开面积、复杂洞口扣减、并入/不扣减细则和材料编号复用关系仍需增强。
4. 首批标准规则模板已完成，复杂体积、质量、混合计量和完整扣减规则还没有完全模板化。
5. 回归评估工具已具备，但还缺用 A6 后的新链路重新上传 3-5 套真实图纸并结合人工清单做验收，以及页面内专项 trace 复核体验优化。
6. 当前重新上传样例已能产出 1 条可复核专项 trace；还需继续补防水房间边界、踢脚线唯一房间绑定和展开面积规则。

## 分阶段路线

### A1. CAD 区域文字绑定

目标：把闭合多段线、HATCH 等面积区域与区域内/附近文字绑定。

输出：

- 区域编号
- 来源文件
- CAD 面积
- CAD 周长
- 图层
- 区域内文字
- 附近文字
- 房间/空间标签
- 项目标签
- 区域置信度

验收：

- 能解释“某个面积为什么属于某个房间或某个吊顶/地面区域”。
- 不再只靠图层名判断区域用途。
- 面积小于 0.5㎡ 的局部碎片默认不进入项目绑定主候选。

### A2. 项目与区域绑定增强

目标：图纸项目不只匹配 CAD 图层，还要匹配区域文字、房间名、项目标签、材料/做法编号。

验收：

- “石膏板饰面吊顶”能优先绑定到含天花/吊顶/石膏板标注的闭合区域。
- “洗手间墙面防水高度1800”能绑定到洗手间区域。
- “天棚喷刷涂料”可复用对应天棚/吊顶区域，但保留规则差异。

### A3. 房间边界与净周长

目标：形成房间级边界模型。

输出：

- 房间面积
- 房间周长
- 门洞/开口候选
- 洞口扣减候选

验收：

- 洗手间、餐厅、厨房等房间可形成面积和周长。
- 同一区域可被地面、防水、墙面、踢脚线等不同规则复用。

### A4. 专项算量器

按优先级实现：

1. 吊顶/天棚：水平投影面积，按标准规则扣减/不扣减。
2. 地面：封闭区域面积。
3. 墙面防水：房间净周长 × 防水高度，扣门洞候选。
4. 踢脚线：墙边净长度，扣门洞候选。
5. 天棚/墙面涂料：复用天棚或墙面区域，按展开/投影规则区分。

验收：

- 每个工程量必须有 `calculation_trace`。
- 每个扣减/不扣减必须能追溯到标准规则。
- 无证据项目不得填工程量。

### A5. 标准规则执行器

目标：把标准库 `quantity_rule_text` 映射为可执行模板。

首批规则模板：

- `area_horizontal_projection`
- `area_floor_boundary`
- `length_wall_perimeter`
- `wall_area_by_perimeter_height`
- `count_by_block`
- `expanded_area_requires_manual_review`

验收：

- 标准规则文字、执行模板、计算公式三者同时输出。
- 规则不支持时，明确阻断并提示人工补量。

### A6. 最终四字段生成与回归

目标：在项目、特征、单位、工程量都通过证据校验后生成最终 Excel。

验收：

- 每条最终行都有项目来源、区域来源、计算公式、标准规则来源。
- 与人工清单对比：项目准确率、漏项率、工程量误差率可统计。
- 至少 3-5 套真实图纸回归通过后再进入正式试运行。
