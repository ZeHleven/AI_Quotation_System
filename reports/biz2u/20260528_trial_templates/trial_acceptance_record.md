## 3. 核心验收项

- [ ] 普通 active 成本库命中可展示成本参考价、AI 价差、AI 来源和证据链。
- [ ] 无底价项目必须人工确认价格。
- [ ] 无底价项目下发成功后只沉淀为 `draft`，不会自动 `active`。
- [ ] 多 active 候选未确认当前成本依据前不能下发。
- [ ] 缺失占位行未补价前不能下发。
- [ ] 预审人工改价、工程量、单位和系统合计联动正常。
- [ ] 预审草稿可保存、关闭后恢复。
- [ ] 普通 `staff` 不能浏览完整成本库。
- [ ] 成本专项角色的查看、编辑、审批启用、归档、同步边界符合 BIZ-2s。
- [ ] 成本库未被系统自动删除、合并、改价或启用 active。
- [ ] 如 active 成本库发生人工变更，已判断是否需要同步 active 到 RAG。
- [ ] 全部问题均已登记到 `trial_feedback_log.csv`。
