# 项目定额与工料机工作台（2026-07-31）

## 目标

清单完成套价后，可在“专业全字段”展开项目定额；点击定额数据行后，在报价草稿下方的独立“工料机明细”模块查看和维护明细。

## 已落地能力

- 计价项目点击行首箭头后，展开区只展示一条定额数据行，不再重复展示“匹配定额主项”、来源标签、定额名称标题、分级路径和字段表头。
- 定额主项字段与“专业全字段”逐项对齐，顺序为定额编码、名称、项目特征、单位、工程量、不含税综合单价、不含税综合合价、人工费、主材费、辅材费、机械费、措施费、管理费、税费。
- 定额数据行整行可点击，不再显示“工料机明细”按钮；点击后只加载下方独立“工料机明细”模块，不改变页面当前滚动位置。
- “工料机明细”模块位于“报价草稿”和“导入甲方清单”之间，未选择定额时显示操作引导。
- 表格操作列不再重复提供“项目定额”快捷入口，避免“展开主项”和“查看工料机”两种动作混淆。
- 工料机支持新增、编辑和删除。
- 可编辑业务字段包括费用类别、库类型、编码、构成类型、名称、工种/子类型、类别、规格、品牌、单位、含量、单价、金额、税率、工作内容和计算规则。
- 工料机变更后立即重算当前项目定额，并同步更新当前项目的计价草稿行。
- 每次变更都使用快照和明细 revision 做并发校验，并记录项目级审计事件。
- 快速审核已移除“施工提示”列；专业全字段固定为 14 个审阅字段，移除区域、采购方式、价格来源、工艺备注、调整及其它费用扩展列。
- 专业全字段保留行展开入口；展开后的定额数据行复用外层字段宽度并隐藏内部表头。
- 统计主材/辅材明细移除项目特征及工作内容；材料按分类、编码、类型、名称、规格、品牌、单位和除税单价聚合，不再因不同施工描述拆分。
- 统计区新增 Excel 导出，工作簿包含“统计汇总、主材明细、辅材明细、人工明细”四个 Sheet。

## 数据隔离

首次打开项目定额时，系统从当前计价草稿和已匹配企业定额生成项目级可编辑快照。后续增删改只作用于这个项目快照及当前项目计价草稿，不修改企业定额 active 版本。

项目定额不是企业定额的实时引用。企业定额版本发生变化时，旧项目快照仍保留项目当时的计价依据和人工调整结果。

## 同步到企业定额库

“同步到企业定额库”是显式选择，不会随普通项目编辑自动发生。

- 项目工料机编辑权限：`cost_editor`、`cost_approver` 或管理员。
- 企业定额同步权限：`cost_approver` 或管理员。
- 无同步权限时，前端直接提示“无权限同步企业定额，请联系管理员授予成本核定权限”，后端继续返回明确的 403 权限错误。
- 同步前校验项目快照来源的企业 active 版本仍是当前 active；企业版本已变化时拒绝覆盖，要求重新生成项目计价草稿。
- 同步写入从当前 active 克隆出的企业定额草稿版本，并重新计算目标定额及整版数据。
- 同步草稿必须继续走企业定额原有审核/启用流程；在正式启用前，当前 active 企业定额不变。
- 重复同步同一项目快照时复用项目对应的企业草稿并替换该定额的工料机，避免重复追加。
- 项目侧和企业定额版本侧都记录同步事件、操作人、原因和前后值。

## 人工验收建议

1. 用有项目计价权限但无 `cost_approver` 的账号编辑一个项目工料机，确认项目定额和当前计价行金额变化，企业 active 定额不变。
2. 勾选“保存后同步到企业定额库”，确认收到无权限提示。
3. 换用 `cost_approver` 或管理员账号，修改工料机并勾选同步。
4. 在企业定额工作台确认生成/更新的是 draft 版本，目标定额金额和工料机已变化，而 active 版本仍不变。
5. 按现有企业定额审核流程启用草稿后，再确认新 active 版本生效。
